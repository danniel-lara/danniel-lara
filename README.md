## 👨‍💻 Sobre mim

Sou um profissional de TI com **mais de 18 anos de experiência em infraestrutura**, atuando desde datacenters tradicionais até arquiteturas modernas em Cloud Computing, Kubernetes e plataformas distribuídas.

Minha experiência abrange ambientes **On-Premises, Cloud e Hybrid Cloud**, com foco em engenharia de infraestrutura, automação, segurança, alta disponibilidade e observabilidade.

Atualmente, trabalho com sustentação de ambientes críticos, modernização de infraestrutura, orquestração de containers, pipelines CI/CD e evolução de arquiteturas resilientes.

> **Minha filosofia:** uma infraestrutura moderna precisa ser segura desde o design, automatizada por padrão, observável em todas as camadas e preparada para falhas.

### 🎯 Minha abordagem

- 🏗️ **Architecture First** — Resiliência, escalabilidade e eficiência.
- 🔐 **Security by Design** — Segurança integrada desde a concepção.
- ⚙️ **Automation First** — Menos operações manuais, mais consistência.
- 📊 **Observability Driven** — Métricas, logs e traces.
- 🔎 **Structured Troubleshooting** — Cluster → Node → Workload → Pod → Application.
- 🚀 **Continuous Improvement** — Confiabilidade e evolução constante.

## 📈 Engineering Metrics

**Confiabilidade não é apenas manter sistemas online. É construir plataformas capazes de evoluir e se recuperar de falhas.**

| Indicador | Objetivo |
|:---|:---|
| 🚨 MTTR | Reduzir o tempo médio de recuperação |
| 🎯 SLI / SLO | Estabelecer objetivos de confiabilidade |
| 🚀 Deployment Frequency | Entregas frequentes e controladas |
| 🔄 Change Failure Rate | Reduzir falhas decorrentes de mudanças |
| ⏱️ RTO / RPO | Garantir recuperação mensurável |
| 💰 Cost Optimization | Eficiência financeira e operacional |
